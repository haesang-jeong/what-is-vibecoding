아쉬운 말 vs 잘 통하는 말

핵심

'예쁘게 해줘'처럼 막연한 말 대신, 눈에 보이는 모양과 행동을 구체적으로 말하세요.

✗ 아쉬운 말

"가계부 앱 예쁘게 만들어줘"

➜
✓ 잘 통하는 말

"날짜·내용·금액을 입력하고, 이번 달 총합을 보여주는 가계부를 따뜻한 노란 톤으로 만들어줘"

✗ 아쉬운 말

"화면이 좀 이상해, 고쳐줘"

➜
✓ 잘 통하는 말

"저장 버튼이 너무 작아. 버튼 크기를 2배로 키우고 가운데에 놓아줘"

✗ 아쉬운 말

"안 돼! 에러 났어"

➜
✓ 잘 통하는 말

"추가 버튼을 눌렀는데 목록에 안 올라와. 화면에 뜬 오류 문구 그대로 복사해 줄게: [...]"

상황별 바로 쓰는 문장 3가지

핵심

막힐 땐 아래 3가지 문장의 괄호만 바꿔서 그대로 따라 말해 보세요.

1. 처음 만들 때 목적과 꼭 필요한 기능만 딱 짚기

"나는 비전공자야. [점심 메뉴를 추천해 주는 룰렛] 웹 화면을 만들고 싶어. 버튼 1개와 결과 화면만 단순하게 만들어줘."

2. 고치고 싶을 때 바꾸고 싶은 곳과 원하는 모습 말하기

"방금 만든 화면에서 [글자가 너무 작아서 안 보여]. 다른 건 그대로 두고 [글자 크기만 키워서] 다시 보여줘."

3. 오류가 났을 때 어떤 행동에서 멈췄는지 알려주기

"[룰렛 돌리기 버튼을 눌렀는데] 아무 반응이 없어. 초보자도 이해할 수 있게 원인을 쉽게 설명하고 고쳐줘."

⚠️ 4부 · 기억하기

조심해야 할 3가지 위험

핵심

AI는 겉모습은 잘 만들지만, 보안 구멍과 내부 엉킴은 스스로 못 챙깁니다.

1
보이지 않는 보안 구멍

현관문 자물쇠가 빠진 예쁜 집처럼, 개인정보가 새어 나갈 수 있습니다.

2
쌓일수록 엉키는 구조

기능이 많아지면 AI도 헷갈려, 하나를 고칠 때 다른 곳이 고장 납니다.

3
오류를 알아채기 어려움

속 구조를 모르면, AI가 그럴듯하게 틀려도 발견하기 어렵습니다.

🛡️ 안전 기준: 혼자 연습할 땐 100% AI에게 맡겨도 되지만, 남에게 공개하거나 돈이 오가는 앱은 꼭 전문가 검사를 받으세요.
